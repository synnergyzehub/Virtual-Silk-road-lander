## Command Reference

### Entity Management

```bash
# Create new entity
python tools/onboard_entity.py --name "EntityName" --region "REG-CODE"

# Start entity services
python config/entity-name/launch.py
```

### NPU Management

```bash
# Register NPU node
python tools/register_npu_node.py --node-id "NPU-001" --region "REG-CODE" --entities "ENTITY-ID"

# Initialize governance
python tools/init_npu_governance.py --node-id "NPU-001" --ecg-key "emperorkey123"
```

### License Management

```bash
# Generate license
python tools/generate_synergyze_license.py --entity "EntityName" --modules "commerce,governance,identity" --term "annual"

# Assign license to NPU
python tools/assign_license_to_npu.py --license "LICENSE-ID" --node-id "NPU-ID"

# Verify license
curl -H "Authorization: Bearer emperorkey123" http://localhost:5001/api/license/verify/LICENSE-ID
```

### Central Management

```bash
# Start all services
python run_central_station.py

# Check service status
python run_central_station.py --status
```

### Component Management

```bash
# Access Genesis Shell
python run_genesis_shell_terminal.py
```

## Workflows

### Entity Onboarding Workflow

1. Administrator creates entity configuration
2. License is generated for the entity
3. NPU node is registered and assigned
4. Entity services are deployed to appropriate region
5. License is assigned to NPU node
6. Entity access is granted to authorized users

### License Verification Workflow

1. Entity attempts to perform an action
2. Action is routed to assigned NPU node
3. NPU verifies license validity
4. Divine Alignment Layer ensures ethical compliance
5. Governance rules are evaluated
6. Action is approved or rejected based on verification

### Trade Execution Workflow

1. User initiates trade on Virtual Silk Road
2. SynergyzeOS license is verified by NPU
3. Divine Alignment Layer validates ethical aspects
4. Governance rules check jurisdictional compliance
5. Trade is executed and recorded
6. ECG oversight is notified for audit purposes
